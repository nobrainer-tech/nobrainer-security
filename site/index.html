What it checks

What your AI checks before you install

  • Spot fake urgency and requests for your tokens or passwords
  • Learn which install steps run scripts or download more code
  • Notice code reaching for your keys, files and browser profiles
  • See where your data could go: web requests, email, telemetry
  • Know what an MCP server or AI tool can do without asking
  • Trust dependencies only when source, version and integrity check out

What it sets up

Let bad updates get pulled before they reach you.

A 14-day wait for newly published package versions is standard, and every dependency review checks it. It gives malicious or broken releases time to be reported and pulled before they reach your project.

New package versions can be malicious or broken. Waiting 14 days gives others time to report and pull them before they reach your project. Age alone does not prove a version is safe, and an urgent security fix may need a reviewed exception.

Your report shows where you stand:

  • Needs setup
  • Configured
  • Verified

Applying the setting is a separate step that needs your approval.

  1. Day 0New version published
  2. Reports come in, bad versions get pulled
  3. Day 14Eligible for your project
  • npm 11.10+ .npmrc → min-release-age=14
  • pnpm 10.16+ → minimumReleaseAge: 20160

What you get

A report you can act on

The report lists findings with evidence down to the exact file and line, the limits of the review, and recommended next steps. It opens as an HTML report with a Markdown view, you can download or copy it, and a scoped Flow fix request is built only from the findings you accept. Creating that request runs nothing.

Does it run the code on my machine?

No. It is read-only by default: it does not install or run the reviewed code, does not change files and does not retrieve secret values.

Is it free?

Yes. NoBrainer Security is free and open source under the MIT license. It runs through NoBrainer.Tech Flow in your own AI assistant.

Does "no findings" mean a tool is safe?

No. This is not an antivirus, a guarantee or a whole-disk scan. It is an extra layer of security before you run unfamiliar code, and it can miss risks.
