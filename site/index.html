01 / 05

A coding test can be the trap.

Fake offer→Coding task→Exposed data

Atlassian documented fake recruiters sending candidates convincing code projects with malware hidden inside. Running them can expose credentials and access to company systems.

Read Atlassian's research ↗21 September 2026
02 / 05

A trusted package. A malicious update.

Trusted name→Bad update→Stolen access

Sonatype reported a 2026 campaign that used compromised publishing access to spread malicious updates through legitimate npm packages and steal credentials.

Read Sonatype's research ↗5 August 2026
03 / 05

A wallet tool that leaks the keys.

Wallet tool→Secret collection→Funds at risk

Socket found a compromised Injective SDK release sending private keys and recovery phrases through fake telemetry. The targeted secrets could give an attacker control of a wallet.

Read Socket's research ↗9 July 2026
04 / 05

Your computer works. Someone else profits.

Math library→Hidden miner→CPU hijacking

Socket identified a fake SymPy package that downloaded and ran a cryptocurrency miner. A useful-looking library concealed code that consumed computing resources.

Read Socket's research ↗21 January 2026
05 / 05

Your browser can expose your accounts.

Browser access→Passwords & sessions→Accounts & wallets

Socket identified malicious Chrome and Edge extensions that harvested login details, session data and wallet secrets. These payloads can expose accounts and enable cryptocurrency theft.
